# Cassette 0.1.0-beta.7

Windows x64 and Linux x86_64 are built from the same source commit. [Windows installer](https://github.com/atilla-m/cassette/releases/tag/windows-v0.1.0-beta.7) · [Linux AppImage, DEB, and RPM](https://github.com/atilla-m/cassette/releases/tag/v0.1.0-beta.7)

- **Library folders** can be added and rescanned individually. Scans show progress and report added, updated, and skipped files. Tracks stay in the library when a drive is disconnected and become playable again after reconnecting and rescanning.
- **Ignored tracks** stay in albums and can play in order. Cassette leaves them out of Stats, mixes, and shuffle. Select several album tracks and right-click to ignore them together. Settings lists ignored tracks and lets you restore them.
- **Listen counting** defaults to 50% of a track's duration, with 25%, 75%, and 100% options. The threshold uses time spent listening.
- **Lyric editing** supports plain text and synced LRC, including stamping a line with the current playback time. Edits live in Cassette's library and can be removed to restore the original lyrics.
- **Gapless playback** is enabled by default for compatible queued tracks. Playback settings include a toggle.
- **CD Rip** has a redesigned overview with drive status, destination, and progress. Obsidian and Light were checked with a simulated disc.

Windows and Linux AppImage updates are verified with Cassette's bundled updater key. DEB and RPM users can install the newer package through their package manager.
