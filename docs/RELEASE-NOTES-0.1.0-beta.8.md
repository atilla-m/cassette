# Cassette 0.1.0-beta.8

Windows x64 and Linux x86_64 are built from the same source commit. [Windows installer](https://github.com/atilla-m/cassette/releases/tag/windows-v0.1.0-beta.8) · [Linux AppImage, DEB, and RPM](https://github.com/atilla-m/cassette/releases/tag/v0.1.0-beta.8)

- **Listen counts** use playback progress. At the default 50% setting, a two-minute track qualifies after one minute of playback. Pauses, stalls, and jumps caused by seeking add no listening time.
- **Windows media controls** reach the player window again. The fix was verified with simulated Windows play, pause, next, and previous commands.

Windows and Linux AppImage updates are verified with Cassette’s bundled updater key. DEB and RPM users can install the newer package through their package manager.
