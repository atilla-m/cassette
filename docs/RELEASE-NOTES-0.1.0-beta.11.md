# Cassette 0.1.0-beta.11

[Windows installer](https://github.com/atilla-m/cassette/releases/tag/windows-v0.1.0-beta.11) · [Linux AppImage, DEB, and RPM](https://github.com/atilla-m/cassette/releases/tag/v0.1.0-beta.11)

- Synced lyrics keep the same wrapping and spacing as the active line changes.
- Choose **Play count** or **Listening time** in **Settings → Listening history**. Listening time records new playback, including partial listens, and stays on this device. The setting applies to the library, sorting, and Stats.
- Windows media controls display the current album cover, including artwork you edited in Cassette.
- Right-click an album track and choose **Select tracks** to start a bulk selection. Use the selection menu to like tracks, add them to a playlist or the queue, or ignore them. Press Escape or click outside to clear the selection. The Settings shortcut guide lists the controls.
- Up Next keeps the current track visible, makes individual removal easier, and skips ignored tracks in both regular playback and shuffle.
- Settings and Playlists use layouts consistent with Stats and CD Rip. Playlist details include song search.

Windows and Linux AppImage updates use Cassette’s bundled updater key. DEB and RPM updates are available as package downloads.
