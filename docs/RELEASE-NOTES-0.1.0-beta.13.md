# Cassette 0.1.0-beta.13

[Windows installer](https://github.com/atilla-m/cassette/releases/tag/windows-v0.1.0-beta.13) · [Linux AppImage, DEB, and RPM](https://github.com/atilla-m/cassette/releases/tag/v0.1.0-beta.13)

- Cassette keeps measuring playback when the audio clock repeats a position before catching up. New plays are recorded after their measured listening time is saved.
- Older plays with no saved duration show **Time unavailable** in listening totals.
- The Songs list has aligned columns for plays and listening time, with more room for album names. Listening activity stays visible in the compact layout.

Windows x64 and Linux x86_64 use the same source commit. Windows and Linux AppImage updates use Cassette’s bundled updater key. DEB and RPM updates are available as package downloads.
